Une application web de suivi d'habitudes quotidiennes développée avec React. Idéale pour les familles, colocataires ou groupes d'amis souhaitant suivre et améliorer leurs routines ensemble.

## ✨ Fonctionnalités

- **👥 Gestion multi-utilisateurs** - Suivez les habitudes de tous les membres du groupe
- **✅ Routines quotidiennes** - Créez et gérez vos routines (sport, méditation, lecture, hydratation, etc.)
- **📈 Suivi de progression** - Visualisez votre progression individuelle et celle du groupe
- **💾 Persistance des données** - Toutes les données sont sauvegardées automatiquement dans le localStorage
- **📱 Interface responsive** - Utilisation optimale sur mobile, tablette et desktop

## 🛠️ Technologies utilisées

- **React** - Bibliothèque UI
- **JavaScript (ES6+)** - Langage de programmation
- **CSS3** - Stylisation et responsive design
- **LocalStorage API** - Persistance des données
- **React Hooks** (useState, useEffect) - Gestion d'état et effets


## 🚀 Installation et démarrage

1. **Clonez le dépôt**
   ```bash
   git clone https://github.com/votre-username/dailyhabits-tracker.git
   cd dailyhabits-tracker
   ```
2. **Installez les dépendances**

```bash
npm install
```
3. **Lancez l'application**

```bash
npm start
```
4. **Ouvrez votre navigateur**

```text
http://localhost:3000
```
## 🎯 User Stories implémentées
US1 - Affichage des routines : Visualisation de toutes les routines chargées depuis le localStorage

US2 - Ajout de routine : Formulaire pour ajouter une nouvelle routine à un membre

US3 - Suppression de routine : Possibilité de supprimer une routine non pertinente

US4 - Accomplissement : Marquage des routines comme accomplies pour la journée

US5 - Suivi individuel et global : Visualisation des progressions hebdomadaires
